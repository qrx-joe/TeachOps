## 正文

研序 TeachOps 是面向师范院校与教师培训导师的教学设计预审系统。它基于 AgentTeams 组建多 Agent 团队：Evidence Agent 依据公开课程标准与合成学情建立证据包；Design Agent 只依据证据条目修订教学设计，每条关键建议引用证据编号；Audit Agent 按规则包独立核查目标、评价与学情响应的一致性；Manager Agent 只做调度与文件传递，不评判教学质量。三个 Skill——build-evidence-packet、revise-lesson-with-evidence、audit-lesson-alignment——均定义输入输出、失败契约与安全边界，可跨学科复用。当关键课标证据缺失时，Evidence Agent 返回 BLOCKED，Manager 中止修订并向导师给出补证清单，避免"看似完整、实则无据"的教案进入评审。初赛已完成四个 Agent Identity、三个 Skill 契约和"分数的初步认识"固定课例的正常与缺证据两套样例，运行材料区分真实运行、fixture 回放与设计。项目以 MIT 协议开源，供教研复用。
