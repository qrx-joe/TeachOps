# 运行证据索引

> 目的：让评委与读者逐项核对每份材料的来源与证据类型，区分真实运行、固定回放与设计。
> 类型定义：`live`（本次真实运行）/ `fixture replay`（固定期望输出回放）/ `design`（方案设计，尚未实现）。
> 维护规则：本索引是 live 状态**唯一事实源**；README、提交清单、PPT 等材料的运行状态表述必须与之一致，不得另建一套状态表。
> 边界：`live` 指"AgentTeams 环境与烟雾测试"或"已登记的实时业务运行"；正常/异常业务流程完成前一律按 `fixture replay` 呈现，不因某日 live 记录而自动表述为"当前服务在线"。
> 新增证据必须登记；live 证据须附获取时间；类型严禁虚标。
