# MVP-001 导师访谈引导与记录模板

> 状态：2026-08-16 建立模板，待访谈 3–5 名师范院校 / 教师培训导师。
> 方法：半结构化访谈。核心原则——**引导导师回忆最近一次真实预审任务**，不提问泛化的"你会不会用 AI"。
> 两周验收基线：`docs/阶段决策-导师可试用MVP.md` 第五节（证据引用正确率、误报/漏报、建议接受/修改/拒绝比例、耗时与卡点、人工审批门为 0）。

## 1. 访谈目标

| 采集项 | 对应两周指标 |
| --- | --- |
| 预审频率与典型场景 | 确认"每周 ≥1 次"的目标用户画像 |
| 最耗时环节 | 导师完成一次任务的卡点 |
| 常见错误类型 | 规则命中的误报/漏报对照 |
| 证据要求与缺据处理 | 证据引用正确率基线 |
| 审批习惯 | 建议接受/修改/拒绝比例基线 |

## 2. 访谈引导问题（按顺序，每题先让导师回忆具体事件）

1. **最近一次预审任务**：请回忆最近一次你审的教学设计——审的是什么、来源、你花了多长时间、最后怎么处理的？
2. **最耗时环节**：整个预审里哪个环节最花时间？（目标-评价对齐 / 课标依据核对 / 学情回应检查 / 修改意见书写）
3. **常见错误**：初稿里你最常看到哪些缺陷？请举最近一个具体例子。
4. **证据核对**：你通常怎么确认一条修改建议是有依据的？依据不明确时你会怎么做（退回、自己补、还是接受）？
5. **审批与记录**：你批准/驳回/要求修改的频率大概怎样？修改依据和前后差异你会保留记录吗？用什么形式？
6. **现状工具**：现在预审用什么？（Word 批注 / 聊天软件 / 通用大模型 / 纸笔）缺什么？
7. **开放**：如果有一个系统能给出每条建议的课标/学情依据、并在缺依据时阻止提交，你最看重它帮你解决哪个问题？

```markdown

- 场景（回忆事件）：

- 最耗时环节：

- 证据核对方式 / 缺据处理：
- 审批与记录习惯：
- 现状工具与缺口：
- 关键引述（脱敏、不加渲染）：
- 信号判断：
  - 场景是否真实成立？ 是 / 否 / 部分
  - 是否愿意保留"依据-决定"记录？ 是 / 否 / 需引导

- 两周验收基线（本场贡献）：
  - 证据引用正确率参考 / 规则误报漏报示例 / 建议接受·修改·拒绝 / 耗时卡点
```

## 4. 成功 / 终止信号（沿用阶段决策）

- 2 周内约到 **≥3 名导师**且场景成立 → 进入评测与试用迭代。
- 约不到 ≥3 名，或 ≥3 名明确表示场景不成立/不愿采用 → 触发 `docs/阶段决策-导师可试用MVP.md` 终止条件，转向方向 A。
